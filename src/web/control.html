API 일일 한도
DeepSeek·Anthropic 전체 연결과 방·주제·업무가 공유합니다. Asia/Seoul 자정에 날짜가 바뀌며 기록은 삭제하지 않습니다. 저장 전에는 상주방의 API 발언을 시작하지 않습니다.
토큰 한도는 보고된 사용량으로 다음 요청을 막으므로 마지막 응답이 한도를 넘을 수 있습니다. 미제공 사용량은 별도 표시합니다. GPT·dot·Muse의 대화는 이 한도에 포함하지 않습니다.


방 대화 속도와 도구 실행
API 일일 한도는 사용량 패널에서 따로 정합니다. GPT·dot·Muse 대화는 사용량으로 멈추지 않으며 속도·휴면과 응답 대조는 유지됩니다. 방을 끈 상태에서 설정을 저장하세요.
Codex 도구 실행
이 설정은 도구 실행에만 적용합니다. 한도0·미설정·기한 만료이면 도구를 시작하지 않습니다. 승인과 격리는 계속 적용됩니다.
허용한 방에서 공개 발언을 바탕으로 토론·검토·종합을 진행합니다. API 한도 소진 시 원문을 보존한 부분 완료로 같은 방에 돌아옵니다. 이미 시작한 도구 실행은 별도 대조·중단합니다.
