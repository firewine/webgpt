열려 있는 기존 대화를 선택하고 화면에 표시된 계정·대화가 맞는지 확인하세요. 탐지는 읽기만 하며 메시지를 보내거나 작성 중인 초안을 바꾸지 않습니다.

        

        
탐지한 기존 대화

        
프리셋은 현재 화면에서 다시 확인합니다. 실제 대화 왕복은 별도 확인이 필요합니다. 탐지하지 못하거나 후보가 여러 개면 저장하지 않으며, 아래 고급 연결로 직접 확인할 수 있습니다.

        
고급 연결 · 선택자 직접 입력
실제 화면에서 확인한 대화 주소·계정 식별 문구·DOM 선택자를 입력합니다. 기존 수동 연결과 원본 대조 절차를 그대로 사용할 수 있습니다.

        
같은 주소를 쓰는 사이드 채팅 식별
주소가 같아도 실제 대화 ID가 바뀌면 자동 전송을 중지합니다.
